# Đa ngôn ngữ (i18n) và đóng góp bản dịch / Localization & translation guide

> **EN** — The UI is translated through plain JSON catalogs in [`locales/`](../../../locales). English (`en`) is the source; Vietnamese (`vi`) is complete. Anyone can add a language with a pull request — no code changes needed. Run `npm run i18n:check` before opening it.
> **VI** — Giao diện dịch qua các file JSON trong [`locales/`](../../../locales). Tiếng Anh (`en`) là bản gốc, tiếng Việt (`vi`) đã đủ. Ai cũng có thể thêm ngôn ngữ bằng pull request, không cần sửa mã. Chạy `npm run i18n:check` trước khi gửi.
