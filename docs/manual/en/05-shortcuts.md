# Keyboard shortcuts

[Contents](README.md) · [Tiếng Việt](../05-phim-tat.md)

On Mac, use ⌘ instead of Ctrl.

## General

| Keys | What it does |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Shift+Z or Ctrl+Y | Redo |

## Playback

| Keys | What it does |
|---|---|
| Space | Play or pause |
| Home | Back to the start |

While you're typing in a field, these keys go to the field.

## Editor tab

| Keys | What it does |
|---|---|
| Arrow keys | Move the selected widget 1 point |
| Shift + arrow | Move 10 points |
| Esc | Clear the selection |
| Delete | Delete the selected widgets |
| Ctrl+D | Duplicate the selected widgets |
| Drag on an empty spot | Select with a box (hold Shift to add) |
| Shift-click | Add a widget to the selection |
| Ctrl+] / Ctrl+[ | Bring forward / send backward |
| Ctrl+Shift+] / Ctrl+Shift+[ | Bring to front / send to back |
| Alt+Up / Alt+Down (in Layers) | Reorder layers |
| Hold Alt while dragging | Move without snapping |
| Hold Ctrl while resizing | Resize without snapping |
| Hold Alt while resizing | Resize around the centre |
| Hold Shift while rotating | Rotate freely (no 15° steps) |
| Double-click the rotate handle | Back to 0° |

## Number fields

| Action | What it does |
|---|---|
| Drag up/down on the field | Change the value |
| Hold Shift while dragging | 10× faster |
| Hold Alt while dragging | 10× slower |
| Type `+=10` or `-=10` | Add to or subtract from the current value |

## Tracks (Preview tab)

| Keys | What it does |
|---|---|
| Alt+Up / Alt+Down | Reorder tracks (Advanced) |
