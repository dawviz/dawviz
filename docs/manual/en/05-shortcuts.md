# Keyboard shortcuts

[Contents](README.md) · [Tiếng Việt](../05-phim-tat.md)

On Mac, use ⌘ instead of Ctrl.

## General

| Keys | What it does |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Shift+Z or Ctrl+Y | Redo |

## Playback

| Keys | What it does |
|---|---|
| Space | Play or pause |
| Home | Back to the start |

While you're typing in a field, these keys go to the field.

## Editor tab

| Keys | What it does |
|---|---|
| Arrow keys | Move the selected widget 1 point |
| Shift + arrow | Move 10 points |
| Esc | Clear the selection; with nothing selected, leave the open precomp |
| Esc (in the **Find a setting…** box) | Clear the search text, keep the selected widget |
| Delete | Delete the selected widgets |
| Ctrl+D | Duplicate the selected widgets (a precomp layer becomes an independent copy; locked layers are not copied) |
| Ctrl+A (⌘A) | Select all layers |
| F2 | Rename the selected layer |
| Alt+click (Option+click on Mac) on a setting's label | Reset that setting to its original value (when it has been changed) |
| Drag on an empty spot | Select with a box (hold Shift to add) |
| Shift-click | Add a widget to the selection |
| Ctrl+] / Ctrl+[ | Bring forward / send backward |
| Ctrl+Shift+] / Ctrl+Shift+[ | Bring to front / send to back |
| Alt+Up / Alt+Down (on a layer name in the Timeline) | Reorder layers |
| Ctrl+K | Split the selected layers at the playhead |
| Ctrl+G | Precompose the selected layers |
| Ctrl+Shift+G | Release the selected precomp (its layers come back to the timeline; asks first if the precomp layer's own animation would be lost) |
| Hold Alt while dragging | Move without snapping |
| Hold Ctrl while resizing | Resize without snapping |
| Hold Alt while resizing | Resize around the centre |
| Hold Shift while rotating | Rotate freely (no 15° steps) |
| Double-click the rotate handle | Back to 0° |

## Panels (Editor and Preview tabs)

| Key | Action |
|---|---|
| Ctrl+B | Collapse or open the Video styles column (Preview tab) |
| Ctrl+Alt+B | Collapse or open the right column (Widget properties / Inspector) |
| Ctrl+J | Collapse or open the Timeline (Editor tab) |
| Arrows (on a panel border) | Resize the panel (Shift: bigger steps) |
| Enter (on a panel border) | Collapse the panel |
| Double-click a panel border | Back to the default size |

## Layer timeline

When the Timeline has focus (click it first):

| Key | Action |
|---|---|
| Drag the middle of a bar | Move the layer in time (every selected layer; keyframes move with it) |
| Drag a bar edge | Trim the start or end (keyframes stay put; other selected layers trim too) |
| Drag the square at a bar's top corner | Fade in (start) / fade out (end) |
| Hold Alt while dragging a bar or the ruler | No snapping |
| Double-click a bar | Open the layer's keyframes; for a precomp, open the precomp |
| Enter | Same as double-click, for the selected layer |
| Ctrl+K | Split the layer at the playhead |
| Ctrl+G | Precompose |
| `[` / `]` | Move the bar so it starts / ends at the playhead |
| Alt+`[` / Alt+`]` | Trim the start / end at the playhead |
| Alt+Left / Alt+Right | Move the selected layers one frame (add Shift: one second); on a phase marker: move the phase |
| Up / Down | Select the layer above / below |
| Delete (on a phase marker) | Remove the phase |
| Double-click the Phases lane | Add a phase there |
| Ctrl + scroll | Zoom in / out horizontally |
| Alt + scroll | Taller / shorter rows |

## Timeline & keyframes

| Key | Action |
|---|---|
| Shift-click a keyframe | Add it to the selection |
| Drag on an empty area | Select with a box (hold Shift to add) |
| Ctrl+A | Select every keyframe of the widget |
| Ctrl+C / Ctrl+V | Copy the selected keyframes; paste at the playhead (spacing kept, works on another widget too) |
| Delete | Delete the selected keyframes |
| Esc | Deselect keyframes |
| Alt+Left / Alt+Right | Move the selected keyframes one frame (add Shift: one second) |
| Left / Right (on a keyframe) | Previous / next keyframe in the row |
| Up / Down (on a keyframe) | Row above / below |
| Enter (on a keyframe) | Move the playhead to the keyframe |
| Hold Alt while dragging a keyframe | Place freely, no snapping |
| Hold Alt while dragging on the ruler | Scrub freely, no snapping to keyframes |
| Double-click a row | Add a keyframe there |
| Press a row's ◆ button and drag down/up | Add (or remove) keyframes at the playhead on every row you pass |
| Ctrl + scroll | Zoom in / out around the pointer |
| U | Show only animated properties |
| Arrows (on a curve handle) | Move the handle (Shift ×10, Alt ×0.1) |

## Number fields

| Action | What it does |
|---|---|
| Drag up/down on the field | Change the value |
| Hold Shift while dragging | 10× faster |
| Hold Alt while dragging | 10× slower |
| Type `+=10` or `-=10` | Add to or subtract from the current value |

## Tracks (Preview tab)

| Keys | What it does |
|---|---|
| Alt+Up / Alt+Down | Reorder tracks |
